# Fashion MNIST Neural Network - TensorFlow/Keras

## 📖 Description
This project uses a feedforward neural network to classify images from the Fashion MNIST dataset. The model recognizes 10 clothing categories from 28x28 pixel grayscale images.

## 📚 Libraries used
- TensorFlow
- Keras
- Matplotlib

## 🧠 Model
- 2 dense layers with ReLU activation
- Final softmax for multi-class classification
- Adam optimizer
- Loss: Sparse Categorical Crossentropy

## 📊 Results
Final accuracy on the test set: about **87%**

## 📦 How to run
Open the file `Fashion_MNIST_Classifier.ipynb` in Google Colab and run all cells.
